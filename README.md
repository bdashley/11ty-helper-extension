# Gemini 11ty & Nunjucks Expert Extension

This extension transforms the Gemini CLI into a context-aware assistant specifically for **Eleventy (11ty)** development. It automates the process of teaching the AI about your custom filters, shortcodes, layouts, and data structures in real-time.

## 🚀 Key Functionality

*   **Automatic & Seamless:** Uses a startup hook to run the audit process in the background. No special commands needed.
*   **Live Architecture Auditing:** Automatically scans `.eleventy.js` and project directories to identify available tools.
*   **Filter & Shortcode Extraction:** Uses regex to find custom logic (e.g., `addFilter`, `addShortcode`) so Gemini can suggest project-specific syntax.
*   **Template Intelligence:** Maps layouts in `_includes` and global data in `_data` to prevent "hallucinated" file paths.

## 🛠 Setup Instructions

### Step 1: Link the Extension

From this directory, link the extension to your Gemini CLI and install dependencies.

```bash
# This command also runs 'npm install'
gemini extensions link .
```

### Step 2: Configure Gemini CLI Context

For the best experience, you should tell the Gemini CLI to always use the context file generated by this extension. The watcher creates a `.gemini-context.log` file in your project root.

You can do this by creating a shell alias. Add the following line to your shell configuration file (e.g., `~/.bashrc`, `~/.zshrc`):

```bash
# Always load the 11ty context file if it exists
alias gemini='gemini --context .gemini-context.log'
```

Now, whenever you run `gemini` from your 11ty project directory, it will automatically have the live context.

## 🤔 How It Works

This extension uses an `on-startup` hook defined in `gemini-extension.json`.

1.  When you launch `gemini` in your project, the hook is triggered.
2.  The hook executes `start-watcher.js`, which launches the main audit script (`dist/audit-11ty.js`) as a detached background process.
3.  This script immediately performs an audit of your 11ty project and then watches for any file changes, rewriting the `.gemini-context.log` file whenever a change is detected.
4.  Because you configured `gemini` to use this log file as context, the AI will always have up-to-date knowledge of your project's structure.

## 📂 Project Structure

*   `package.json`: Manages dependencies and scripts.
*   `tsconfig.json`: Configures the TypeScript compiler.
*   `gemini-extension.json`: The manifest that defines the `on-startup` hook.
*   `GEMINI.md`: The system instructions for Nunjucks/11ty logic.
*   `start-watcher.js`: A simple Node.js script to launch the watcher in the background.
*   `src/`: Contains the TypeScript source code (`audit-11ty.ts`).
*   `dist/`: Contains the compiled JavaScript output.
